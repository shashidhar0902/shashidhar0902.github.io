ARRIVAL RATE (λ)
Rate customers arrive. Follows Poisson distribution in Markovian systems.
λ = 9–10 students/min
SERVICE RATE (μ)
Rate a single server completes service. Exponentially distributed times.

M/M/c MODEL
Markovian arrivals & service, c parallel servers. Stable only if ρ < 1.
ρ = λ / (c · μ)
LITTLE'S LAW

🔍 Root Cause: Both sub-systems critically over-utilised. NV (333%) is the primary bottleneck. 2 servers simply cannot serve 800 students in 2 hours.

Recommendations

❌ NOT FEASIBLE
Option A: Batch Arrivals
Stagger 1,000 students into 4 fixed time-slot batches.
  • 4 batches × 250 students → λ≈2.1/min → ρ < 1
  • Students have varied class schedules
  • Feast = social event — staggering kills it
  • Non-compliance inevitable; impractical to enforce
∴ Theoretically valid. Practically infeasible.
❌
✅ RECOMMENDED
Option B: Add More Servers
Scale server count to bring ρ < 1 for both sub-systems.
  • +5 NV servers → total 7 NV servers
  • +1 VEG server → total 2 VEG servers
  • NV ρ=6.67÷7≈95% ✓ stable
  • Casual staff on feast days → low fixed cost
∴ Feasible, effective, cost-efficient. Preferred solution.
